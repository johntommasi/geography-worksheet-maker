# 教学记录表制作流程

## 适用范围

处理用户提供的“师生有约记录表”或“学科教研活动记录表”图片、名单表格和填写要求。

## 固定流程

1. 读取图片：区分印刷文字、表格线和手写内容，只提取版式结构，不复制原图手写信息。
2. 读取名单：从 Excel 识别工作表、表头、班级和姓名；删除空行和汇总行，保留原有顺序。
3. 轮换选择：建立本次记录的已用姓名清单；按名单顺序选择下一人。若用户提供历史成品，从历史成品中读取已用姓名；无法判断时明确从第一人开始，不得假装已使用过某人。
4. 填写内容：按栏目分别写入，交流内容应包含学生陈述、教师分析、学生诉求；改进措施必须具体可执行；跟进反馈不得与前文重复。
5. 输出成品：优先生成可打印 PDF；若用户要求可编辑，再同时生成 DOCX。生成脚本统一存入 `工具脚本/教学记录表/`。
6. 检查：确认无原图手写残留、姓名班级无误、日期格式一致、表格线和文字不越界，逐页查看 PDF。

## 师生有约内容模板

- 核心交流内容：学生自述 → 教师分析 → 学生诉求。
- 具体改进措施：立即行动、执行频率、检查方式。
- 跟进反馈与确认：已完成事项、当前变化、仍需支持。
- 二次交流安排：明确时间或触发条件；不确定时留空。

## 学科教研活动内容模板

- 活动过程：主题提出 → 课例/数据分析 → 讨论分歧 → 形成共识。
- 主要成果与收获：教学方法、资源建设、难点突破或评价改进。
- 待进一步研究的问题：保留一个可继续研究的具体问题。
- 后续行动：写清任务、负责人和完成时间；未知信息留空。
