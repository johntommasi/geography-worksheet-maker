# 高中地理教学材料制作

## 适用范围

用于本工作区的高中地理 **学案**、**限时练**、**教案** 制作与修改，以及 **师生有约记录表**、**学科教研活动记录表** 的整理与填写。学案、限时练默认复制固定 DOCX 模板填充内容，并同时交付 DOCX 与由该 DOCX 导出的 PDF；只有用户明确要求时才使用 LaTeX 模板。教案默认同时交付 Markdown 与配套 Obsidian Canvas；记录表按用户指定格式输出。

## 教学记录表

当用户提供记录表图片时，先识别表格结构、栏目和手写内容；以印刷文字为模板，去除或不复用原图中的手写姓名、日期、地点、主题和正文。优先重建为清晰的可打印表格，不把原照片直接当成成品背景。

- **师生有约记录表**：从用户提供的 Excel 名单读取姓名和班级，默认按表格原有顺序轮换选择；每次生成前检查已生成记录或用户指定的已用名单，避免连续选择同一学生。首次无历史记录时从名单第一位开始。
- 填写前保留表格原有栏目：教师、日期、班级、姓名、性别、交流地点、交流目标、核心交流内容、具体改进措施、跟进反馈与确认、二次交流安排和签字栏。未知字段留空或按用户明确内容填写，不擅自编造签名。
- **学科教研活动记录表**：保留活动主题、时间、地点、主持人、记录人、应到/实到/缺席、活动过程、主要成果、待研究问题、后续行动、教研资源附件和审核栏；原图手写内容只用于理解版式，不直接复制。
- 记录表成品必须进行版面检查：栏目不越界，中文清晰，表格线完整，手写痕迹已去除，填写内容与栏目匹配。若用户未指定成品格式，优先交付可打印 PDF，并保留可复用生成脚本到 `工具脚本/教学记录表/`。

## 制作前固定顺序（必须执行）

每次新建或修改材料，严格按以下顺序执行，不得跳过：

1. **先读对应模板或范例**：制作学案、限时练时，完整读取对应的 DOCX 模板并检查页面、分栏、页眉页脚、段落、图片、题号和答案区；制作教案时，完整读取[教案制作流程](references/教案制作流程.md)、本地教案规范和一份同类教案范例。只学习与当前成品类型有关的结构和格式。
2. **再出选择式制作前清单**：把已确认的版式规范写入清单，将可配置项目写成勾选项，并结合用户要求预选默认项；清单发给用户确认。
3. **确认后再读资料并制作**：用户确认清单后，才读取教材、参考资料和图片；按成品类型创建或修改 `.docx`、`.md` 和配套 `.canvas`，并完成相应检查。

模板学习阶段只做读取和版式归纳，不得提前改稿、命题、抽图、填充 DOCX 或导出 PDF。

## 第一步：先给出制作前清单（必须执行）

收到制作或修改教学材料的请求后，先阅读[制作前清单](references/制作前清单.md)，结合用户已给出的信息完整预填，并将清单发给用户确认。

- 此步骤只确认制作范围，不开始编写题目、抽取教材图片、创建或修改 DOCX、导出 PDF。
- 未明确的信息写“待确认”或“按默认”，不得擅自补充会影响教学设计的选择。
- 用户明确回复“确认”“按清单执行”或给出补充后的最终要求后，才进入后续制作。
- 即使需求看似完整，也必须先展示这一清单；用户要求“直接执行”可视为对已展示清单的确认。

## 确认后：读取资料与规范

1. 完整读取 `要求/` 中与任务有关的文件，作为本地最高优先级规范。
2. 读取用户提供的参考资料、同类范例和 `assets/` 中对应的地理课本内容，再开始命题或写讲解。
3. 查阅 `工具脚本/latex/固定模板/` 中对应的固定 DOCX 模板；原模板只读，复制并按课次改名后，只在正文、题目、图片和必要字段上做课次化填充。
4. 若用户要求“近五年考情”，检索近五年权威资料；不得编造考情结论。

路径、默认信息和版式细则见[工作区约定](references/workspace-conventions.md)。

## 固定模板版式规范（学案与限时练）

以下规范来自固定模板和用户提供的示例，制作前须在清单中复述并核对：

- 页面固定为 **A3 横向、2 页、左右双栏**，中间有分隔线；四个栏位内容密度要均衡，不能出现大片连续空白，也不能越过页底安全区。
- 页眉居中保留模板标语，页脚保留页码；第一页左栏顶部使用学校 Logo、学段和学科标题，右侧为“内容、编辑、校对、审核、使用时间”等表头信息。
- 表头默认“编辑：陈浩然，校对：史文静”；除非用户另有要求，不得改成其他姓名或留空。
- 正文、题干、选项、图注、解析和参考答案统一使用宋体小四（12pt）；只有学校标题、栏目标题和题组标题按模板层级放大或着色。
- 学案结构按“学习目标—新课标要求—知识梳理—随堂练习—参考答案”组织；限时练沿用其专用模板，不得混用学案结构。
- 题目必须按阅读顺序连续编号，题组标题注明题号范围（如“题组一（第1—4题）”）；跨栏或跨页时写明“续”，不得让题组看起来像错位或乱序。
- 每道题的题干必须紧跟自己的选项；短选项可 A—D 同排，较长选项采用两行两列，选项起始位置和列宽保持一致。不得为省空间把长选项挤成难以辨认的一行。
- 限时练中的图片统一放在版面的右侧。黑白图片按正常尺寸设置；彩色图片如果缩小后文字和细节更清楚，可适当缩小，并优先在白板上直接放大展示，不强行塞入试卷正文。
- 随堂练习优先采用“材料/读图—设问”题组；图、材料、题目和答案一一对应。复杂的教材图（标注密集、坐标或多层结构）使用清晰裁切的通栏大图；简单示意图才采用图文并排。图片不得缩到无法读字，也不得重复放置造成空白浪费，题注紧跟图片下方。
- 参考答案必须置于全文最后，完整覆盖知识梳理、选择题和综合题；答案字号与正文一致，不得缩小到不可读。答案区不得越界，必要时通过删去重复题、精炼答案或调整题组位置解决溢出。
- 每次交付前至少完成两轮渲染检查：第一轮检查题目顺序、栏位填充和图片清晰度；第二轮检查页底、答案、字体、页码和打印安全区。

## 成品类型与内容边界

### 学案

- 使用 `工具脚本/latex/固定模板/示例模版2.1 学案.docx`；原文件只读，先复制到成品目录并按“课次课题-学案.docx”命名。
- 保持 A3 横向、双页、双栏、页眉页脚与末尾参考答案的固定结构。
- 默认：编辑 `陈浩然`，校对 `史文静`；除非用户另有要求。
- 正文为宋体、小四；小节标题沿用模板的红色标题样式。
- 内容应围绕“学习目标—核心知识/探究—随堂练习—参考答案”展开。随堂练习以选择题为主，可搭配少量填空或简答；不得在练习后堆砌无关内容。

#### 随堂练习的高考化命题

- 用户提出“向高考题看齐”“近五年考情”或类似要求时，先归纳检索到的高频考查角度，再原创命题，不照抄试题。
- 优先组织为 2--4 组“材料/读图—设问”题组：至少包含材料或读图之一，优先将二者结合；图片优先采用本课教材图。
- 每个题组围绕同一证据设计 2--4 问，考查获取图文信息、调用概念、推理判断或情境应用，难度由基础到提升。
- 可保留少量基础选择题作即时诊断，但不得以大量脱离情境的碎片化单选或填空替代题组；综合题只保留能检验关键能力的设问。
- 题目、图号、材料与答案必须一一对应；答案给出规范术语和必要依据，保持简洁。

### 限时练

- 使用 `工具脚本/latex/固定模板/示例模版-限时练-城镇化.docx`；原文件只读，先复制到成品目录并按“课次课题-限时练.docx”命名。
- 保持标题、限时与学生信息栏、A3 横向双页及答案区的固定样式。
- 不得未经说明将限时练改成学案，或反向替换。

### 限时练讲义

- 限时练讲义是教师讲解限时练时查看的备课稿，只交付普通 Markdown（`.md`）格式，不需要排版。
- 不套用 A3、双栏、LaTeX、固定试卷模板或打印版式，也不生成 PDF 或其他排版成品，除非用户另行明确要求。
- 讲义应围绕原限时练逐题讲解，并结合学生成绩、题目正答率和错题表现整理知识框架、解题思路、易错点、规范答案及课堂讲解顺序。

### 教案

- 先阅读[教案制作流程](references/教案制作流程.md)及 `要求/教案规范.md`。
- 默认同时输出完整教案 `.md` 和配套 Obsidian 白板 `.canvas`；不套用 A3、双栏、LaTeX 或 PDF 规范，除非用户明确提出。用户明确说不需要白板时才省略 `.canvas`。
- 教案中的举例要使用学生在眼皮子底下能够看到、理解或实地接触的例子；以教室为中心，优先覆盖赞皇县范围内的校园、村镇、道路、河流、地形、农业、天气和日常生活现象。只有本地经验不足以解释概念时，才补充更大区域或全国案例，并说明尺度变化。
- 按规定的八个部分组织：章节、课型、课题（课时）、教学目标、教学重点、教学难点、教学设计、板书设计。
- 若教案为 2 课时或多课时，教学目标、教学重点、教学难点必须按课时分别列出，不能把多课时内容堆在同一组条目中。
- 教案默认采用“可直接照讲的详案”，不是只列活动名称的流程表。每课时必须先列知识点清单，再把核心知识写成教师可直接使用的讲授内容。
- 教学流程按 2—4 个主要知识板块组织。每个板块至少写清时间、可直接使用的教师讲稿、读图或推理过程、设问、预期回答、必要的学生记录要点和过渡语；不能只写“展示图片、学生讨论、教师总结”。
- “纠错与追问”只在存在真实易错点时设置，必须针对当前设问或学生预期回答，不得借纠错突然补充前文尚未讲授的新知识。若需引入新条件，应先完成讲解，再单独设问、回答和纠错。
- 以教师实际抄写到教案本并据此授课为目标：概念解释、规律推导、读图方法、高考考法和课堂检测答案均应可直接使用。
- **板书设计必须是独立部分**：统一置于 `## 八、板书设计`，不得在“教学设计”各环节中插入“板书：”“板书/笔记：”或重复的板书方案。教学流程中如需提示学生记录，只写“学生记录要点”或“必记句”，不冒充板书设计。
- 多课时教案的“八、板书设计”须按课时分别列出，与对应课时的知识主线一致，便于教师直接抄入教案本；不得把板书分散在流程中再让教师自行汇总。

#### 教案配套 Obsidian Canvas

- Canvas 是教案的简化思维脉络，不复制整篇教案。中心节点写课题与总主线；按课时分支，并依次组织“目标/导入—核心知识—因果链或读图方法—易错点—检测与板书”。
- 多课时教案必须在白板中分成独立课时分支；节点之间用有方向的边表示讲课顺序或因果关系，不能只堆放互不连接的文本框。
- 单个节点保持短而完整，优先使用关键词、箭头和层级列表；抽象内容要保留必要的推导步骤，不能因简化而只剩结论。
- 文件名默认与教案同课题，例如 `{课次}{课题}-教案.md` 配套 `{课次}{课题}.canvas`；两者放在同一项目目录。用户已有指定 Canvas 文件时直接更新该文件。
- 交付前解析 Canvas JSON，检查节点 ID 唯一、所有边引用的节点存在、课时与教案一致，并确认不存在孤立的主要知识节点。

#### Canvas 图制作标准

- 默认采用**横向思维导图**，参考“左侧中心主题—向右展开分支”的结构；除非用户明确要求，不使用上下堆叠的双栏流程卡片作为默认样式。
- 根节点放在画布左侧或左侧中部，写课题、总主线或核心问题；一级分支从根节点向右展开，按知识板块、课时或学习任务纵向错开排列。
- 二级、三级节点继续向右展开，形成“主题—板块—核心概念—过程/例证—易错与检测”的层级，不把所有内容挤在同一层，也不把整段教案复制进一个节点。
- 节点文字保持短而完整：每个节点只承载一个知识点或一个教学动作，优先使用关键词、箭头、因果链和分层短句；复杂解释拆成相邻节点。
- 默认使用颜色表达层级和功能：根节点使用醒目色；一级分支使用统一的主题色；知识节点使用浅色；过程、答题方法或例证可使用另一种辅助色；易错点、检测和安全提醒使用警示色。颜色服务于阅读，不用颜色代替文字层级。
- 连接线应表达讲解顺序、因果关系或从属关系，方向统一从左向右；每个主要节点至少有一条入边或出边，禁止出现孤立的主要知识节点。
- 布局要留出明显空白：根节点与一级分支之间、一级分支与子节点之间保持一致间距；同层节点不重叠，文字不被遮挡，避免大面积交叉线和无意义长连线。
- 保留原教案的知识主线，但允许将“目标/导入、核心知识、因果链或读图方法、易错点、检测与板书”压缩成思维导图关键词；Canvas 是讲课导航，不是教案全文排版稿。
- 修改或新建后必须校验 Canvas JSON：节点 ID 唯一、边的 `fromNode`/`toNode` 均指向现有节点、没有重复边或孤立主节点；打开 Canvas 实际查看一次，确认阅读方向、颜色层级和节点间距符合上述标准。

## 图片与读图题流程

1. 优先从 `assets/` 的对应教材中提取清晰、与本课直接相关的插图。
2. 教材没有合适插图时，才检索权威或许可清楚的网络图片，并记录来源。
3. 前两者均不可用时，再绘制简洁、标注规范的示意图。
4. 每张图必须服务于知识理解或读图设问，配图题注；避免装饰性图片。

### 教材提取图与临时文件清理

- 从教材 PDF 提取的整页图、裁切图、预览图和渲染图均视为任务临时文件，统一放入 `tmp/` 下以本次任务命名的目录；不得把它们长期保存到 `PARA/03资源/产出/assets/`、工作区根目录或固定模板资源目录。
- 最终成品核验通过后，删除本次产生的教材提取图、页面渲染图、裁切中间图、一次性脚本、编译缓存和无用备份。教材原始 PDF 与最终交付文件必须保留。
- 只有用户明确要求长期保存，或图片经过人工整理、确实会被多个成品重复使用时，才可转存为正式资源；保存前应使用清晰、可检索的名称，不能保留 `image1.png`、`page-01.png` 等临时命名。
- 可复用的提取或裁切脚本应整理到 `工具脚本/` 下名称明确的子目录；只服务于单次任务的一次性脚本在任务结束后删除。
- 清理前先检查 `.tex`、`.md` 和脚本是否仍引用这些文件；有引用时先改为可重建流程或确认最终成品已独立封装，再删除。每次交付前都要完成这一检查，不等待用户再次提醒。

## 内容与答案要求

1. 题干、术语、图例和答案均以教材及规范为依据，题目难度符合高中阶段。
2. 题型和考查角度要有区分，避免重复设问、答案规律明显或表述含混。
3. 参考答案必须置于学案末尾，简洁、可核对，并始终留在第二页版心内。

## 学案、限时练的 DOCX 制作与输出

1. 固定 DOCX 模板只读；每次复制到成品目录再填充，绝不直接覆盖模板。
2. 默认通过 Word 文档结构或 OOXML 替换正文、题目、图片和表头，尽量保留原有分栏、段落、字体、页眉页脚、文本框及图片锚点。
3. 成品 DOCX 默认保存到 `output/docx/`，PDF 默认保存到 `output/pdf/`；用户指定其他位置时从其要求。
4. 使用 LibreOffice 将最终 DOCX 导出 PDF；如果用户明确要求使用 Microsoft Word 导出，则按用户要求执行。
5. 每次有实质性编辑后均须渲染 DOCX 或导出的 PDF 并逐页检查；不得只做文本提取或结构检查后交付。

## 强制版式核验

每次编译或调整版式后，都要：

1. 确认 DOCX 导出的 PDF 恰为 2 页、A3 横向。
2. 渲染并逐一查看两页的四个栏位，不得只检查页数或整页边界。
3. “两页占满”是硬性要求：每个栏位的有效内容应接近版心底部，不得留下明显的大块连续空白；仅有页脚安全距离和正常段尾留白可以保留。
4. 核对栏宽、页眉页脚、正文宋体小四、图像清晰度、题号连续性与答案是否越界。
5. 出现空白时，优先补充与本节直接相关的读图任务、材料题、综合探究、答题模板或评分要点；禁止用无意义文字、纯占位框或单纯拉大空白间距凑满页面。
6. 出现溢出时，先删除重复内容、精炼表述或调整题组位置；任何文字、选项、图片和答案都不得触碰或越过版心底部。
7. 每次交付前至少完成两轮版式检查：第一轮查内容密度与四栏填充，第二轮查边界、页底、答案和打印安全区。两轮均通过后才可交付。
8. 修正后必须重新编译并复查；只清理本次产生的临时文件，不动用户原有文件。
