# 高中地理教案制作流程

仅在用户要求新建或修改“教案”时阅读本文件。成品为 Markdown（`.md`），不生成 PDF、Word 或 LaTeX，除非用户另有要求。

## 制作前确认

先使用制作前清单确认课次、教材章节、课时数、课型、教学重点和输出文件名。用户确认后，读取：

1. `要求/教案规范.md`；
2. `要求/高一地理教学规范.md`（如存在且与任务相关）；
3. 对应教材章节、用户提供的参考教案和题目资料。

## Markdown 固定结构

按以下八部分依次撰写，不随意合并或遗漏：

```md
# 《课题》教案

## 一、章节
## 二、课型
## 三、课题（第 X 课时，共 X 课时）
## 四、教学目标
## 五、教学重点
## 六、教学难点
## 七、教学设计
## 八、板书设计
```

若一节内容安排为 2 课时或多课时，`教学目标`、`教学重点`、`教学难点` 必须按课时拆分，例如先写“第一课时：……”，再写“第二课时：……”。不要把所有课时的目标和重难点混在一组条目中，避免教师二次拆分。

## 教学设计要求

1. **重难点突出**：说明常见考法、设问角度或对应练习；用“提问”“敲黑板”“记入笔记本”等教师语言，帮助学生提炼可考结论。
2. **备学生**：写清可提问的对象、问题和预期回答；标出教材易错点、易混概念及纠正方式。
3. **案例突破**：优先选择教材、高考题或有代表性的真实案例；需要时配正向与反向案例，服务于重难点突破。
4. **依托教材、联系实际**：每个核心活动应能回到教材图文、地理现象或生活实际，避免空泛的活动描述。
5. **目标回扣**：结尾用小结、练习或提问核对学习目标是否达成，并说明未达成时的补救安排。

教学设计可用表格呈现“教学环节、教师活动、学生活动、设计意图、时间”，也可按环节分段；选择以清晰、可直接上课使用为准。

## 输出与保存

- 默认文件名：`{课次}{课题}-教案.md`。
- 默认保存到工作区根目录，与已有教案保持一致；用户指定位置时从其要求。
- 不创建用于生成教案的一次性脚本；若确有可复用的自动化需求，脚本只能存入 `工具脚本/` 的具名子文件夹。
- 交付前核对八部分齐全、课时数一致、案例与教材内容准确、教学活动能回扣目标。
