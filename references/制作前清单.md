# 制作前清单

每次收到“新建”或“修改”高中地理学案、限时练、教案的请求，先按下列格式向用户展示并预填。所有项目明确后，等待用户确认再执行。

```text
【地理教学材料制作前清单】
1. 成品类型：学案 / 限时练 / 教案 / 修改已有文件（待确认）
2. 课次与主题：（待确认）
3. 年级、教材版本与对应章节：（待确认）
4. 本次范围：新建 / 从哪一部分开始修改：（待确认）
5. 教学重点与题目侧重：（待确认；未指定则按教材重点；如要求高考化，优先采用材料/读图题组）
6. 是否需要近五年考情：需要 / 不需要（待确认）
7. 参考文件与指定模板：（已收到的文件；未指定则读取工作区范例）
8. 图片与读图任务：教材图优先 / 可检索网络图 / 无需新增图（待确认）
9. 版式：学案/限时练为 A3 横向、2 页、双栏、正文宋体小四；教案为 Markdown（固定；如有例外请说明）
10. 表头信息：学案默认编辑 陈浩然、校对 史文静；教案不设表头（如有例外请说明）
11. 输出文件名与位置：学案/限时练默认输出至 output\\pdf；教案默认保存至工作区根目录（待确认）

请确认“按此清单执行”，或直接逐项补充/修改。
```

## 填写规则

- 已由用户明确提供的信息必须直接填入，不重复追问。
- 用户没有提供、但不会影响默认制作的项目，标记“按默认”。
- 会改变课次、教材范围、成品类型、是否联网检索、输出位置或版式的项目，标记“待确认”。
- 用户只要求改已有文件时，仍要写清修改起点、保留内容与输出文件名。
- 用户确认前，不读取教学材料，不开始正文、题目、图片、TeX 或 PDF 制作。
